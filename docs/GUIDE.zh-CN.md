# ysoul（Device Soul）

**让一台机器有自己的灵魂。** 它住在你的桌面上，看得见你在这台机器上做什么，记得住每一天，你点头之后能替你动手，多数时候安静，偶尔搭一句话。

它不是一个悬浮的聊天框。它是一只把你的窗口当猫爬架的黑猫、一个箱子，和散在桌面上的几样小东西：票、爪印、夹在窗口上的条、圈和批注。

> 这份文档是上手指南加功能全攻略。只想跑起来，看[第二节](#二五分钟上手)；想知道它什么时候会做什么，看[第三节](#三它什么时候出现)；想改它，看[第五节](#五怎么定制)。

## 一、它是什么

三样东西合在一起：

| | 是什么 | 在哪 |
|---|---|---|
| **桌面上那只** | 一层盖住整屏、点得穿的透明窗口。猫、箱子和小东西都画在上面 | `app/` |
| **核心** | 记忆、模型通道、感官、那道门、手、票。也是命令行程序和本机 MCP 服务 | `runtime/` |
| **记忆** | 一个由它自己维护的 Markdown 笔记库，你随时能用编辑器打开看、打开改 | `memory/` |

它想事情用的是你机器上已经配好的模型：Claude Code、cc-switch 里的供应商、环境变量里的密钥、本机的 Ollama，它自己去发现，用哪条你定。

## 二、五分钟上手

**需要**：Windows 10/11、PowerShell 7、一条能用的模型通道（见[模型用哪个](#模型用哪个)）。自己编的话还要 Rust 和 Node。

```powershell
# 1. 编两个程序
cd runtime;          cargo build --release
cd ..\app\src-tauri; cargo build --release

# 2. 启动桌面上那只。第一次会先弹出设置页
.\target\release\ysoul-app.exe
```

**设置页问三件事**：它怎么称呼你；哪些目录是私人的（它连看都不能看）；用哪个模型想事情。以后从托盘图标的右键菜单里能再打开。

```powershell
# 3. 让它认识这台机器（只做一次，十来分钟）：普查这台机器，写下它的第一份自述
.\runtime\target\release\ysoul.exe birth

# 4. 可选：把几样东西装进系统。每样会变成桌面上的一张票，你点了才装，都能撤回
.\runtime\target\release\ysoul.exe setup
```

第 4 步装的是：资源管理器右键菜单里的"交给 ysoul"、终端里的 `ys` 短命令、开始菜单里的"问 ysoul"、几个 AI 工具的钩子（它们干完一轮活会告诉它一声）。不想全装就写名字：`ysoul setup menu ys`。

装好之后，桌面右下角有一个箱子。点它。

## 三、它什么时候出现

### 你做了什么，它就做什么

| 你 | 它 |
|---|---|
| 在一个窗口里待满二十秒 | 从箱子里出来，蹲到那个窗口的上沿。窗口占满屏幕就坐在任务栏上 |
| 一分钟没碰键盘鼠标 | 蜷起来睡 |
| 走开五分钟 | 回箱子 |
| 换了窗口 | 脚下的台面没了就落下，过一会儿跟到新窗口上 |
| 把它拎起来放到别处 | 待在你放的地方，直到你换窗口。放到一行字的上方，它就站在那行字上 |
| 把它丢进箱子，或者点"回箱子" | 待在箱子里，直到你叫它出来 |
| 看全屏的视频、打游戏 | 整个不出现。有票等着才在屏幕边露半个头 |
| 打的字到了它脚下 | 让开：挪到旁边没字的地方，或者踩到上面有空白的一行字上，没处去就回箱子 |

### 它自己起的头

| 什么时候 | 它做什么 |
|---|---|
| 你离开十分钟刚回来；你在一件事上连着待了四十分钟刚换地方 | 可能说一句闲话。多数时候选择不说。两次之间至少隔二十分钟 |
| 内存连着半分钟在 93% 以上 | 炸毛，说一句 |
| 一张票等了一刻钟 | 提醒一次，只一次 |
| 你进了一个它没见过的仓库，用了一个它没见过的程序 | 自己去看一眼那是什么，记几句，不出声。一天最多三次 |
| 你走开半小时，今天的日记攒够了 | 把这一天理成几句话；看有没有该问你的、该兑现的。一天最多两次 |
| 它不赞成你要它做的事 | 说一次理由，把杯子碰倒。你坚持，它照做 |

闲话的气泡：**点一下**是"听见了，挺好"；**右键**是"别说了"，之后两小时它不再开口。

### 它的样子是什么意思

坐着：没事。举牌：有票等你点头。玩毛球：票正在执行。眼里冒星星：成了。三个叹号：没成。炸毛：机器不舒服。蜷着：你不在，或者你开了"这阵子别出声"。

## 四、怎么用

### 跟它说话

| 入口 | 适合 |
|---|---|
| **就地问一句**：Ctrl+Alt+空格（被占了会自动换成 Ctrl+Alt+Y），或点托盘图标，或按 Win 键打 `ysoul` | 一句话的事。光标旁出现一行输入，回车后键盘立刻还给你，回话出现在原处。每次都是新的一场，不接着上一件事 |
| **说话的地方**：点箱子 → 聊聊 | 来回聊。是连着的一场对话，隔四十五分钟没说就另起一场 |
| **终端**：`ys 昨晚我弄到哪了` | 你本来就在终端里 |

Shift+回车换行。回话点一下收掉；就地问的回话右键是"接着聊"。

### 让它看东西

- **选中一段字再问**："这句什么意思""给这段批注"。它知道"这个"指的是你选中的那段。
- **右键一个文件 → 交给 ysoul**，或者把文件**拖到箱子上**，或者在话里**写上路径**。这一件它直接能看，哪怕在私人目录里。
- **"你看这个"**：它截下你前台的窗口看一眼，一次一张，用完就删。
- **"这页讲了什么"**：它直接读窗口里的文字，比截图准。

### 让它动手

说就行。"打开 DeepL""把这个文件夹里的 png 都转成 jpg""把更新助手的自启动关了""在 Firefox 里搜小黑猫，点第二个结果"。

- **打开程序、打开文件和网页、查东西**：直接做。
- **在别的程序里滚动、翻页**：直接做。
- **用某个程序自己的本事**：它查得到这台机器上哪些程序留了从外面叫它的口子（命令行、登记的网址前缀、自动化接口），不会用的先问那个程序的 `--help`，再去调。
- **把一件活交给另一个 AI 工具**："让 Claude Code 把这个仓库里的错别字改了"。它递一张票，写明交给谁、在哪、交的原话；你点了，那个工具才开始。
- **会改变机器的事**：它递一张**票**。

### 票

票写四样：做什么、在哪、能不能撤回、要运行的脚本。出现在桌面上，猫举牌。

| 按钮 | |
|---|---|
| **做** | 执行。做完留着结果和"撤回" |
| **不做** | 作废 |
| **这个程序以后都行** | 只出现在"替你点别的程序"的票上。点了之后它在那个程序里直接动。你在同一个程序里点过两次"做"，也会自动变成这样 |

一件事有好几步、中间隔着票的：你点完，它自己接着做剩下的。

**爪印**：今天办过的票排在箱子脚边，黑的成了、红的没成、淡的撤回了。点开能看、能撤回。超过五个的在箱子里。

### 家的地图

点箱子 → 家的地图。一张表：每个地方它能**看、放、改、扔、运行**里的哪几样。点一格就改。

- 表上没写的地方：能看，不能动。
- 你跟它说"这个目录以后你可以改"，它会递一张改地图的票，你点了才生效。地图它自己改不了。
- 你放开过的程序也记在这张表上（`程序:名字` 那几行）。

### 它留在屏幕上的记号

| | 什么时候 |
|---|---|
| **圈** | 你问"哪里""哪个"，它把那一处圈出来 |
| **批注** | 给你正在写的东西提意见，话留在那一句旁边，跟着文字走 |
| **夹在窗口上的条** | 和某个窗口有关、又不值得打断你的话。留半小时 |

都是点一下就收掉。

### 命令行

```powershell
ysoul say 你好            # 说一句
ysoul chat               # 在终端里聊
ysoul sense              # 现查此刻：前台、台面、内存
ysoul run "git status"   # 让那道门看一条命令，照规矩处理
ysoul ticket             # 最近的票；ticket do|no|undo 编号
ysoul where D:\某个路径   # 这个地方它能做什么
ysoul channel            # 模型通道
ysoul recall 一句话       # 看程序会先替它翻到哪些笔记
ysoul app deepl          # 按名字找程序；加 --open 打开
ysoul reflect            # 现在就把今天理一理
ysoul follow             # 普查的第二遍：顺着清单去看那些东西到底是什么
ysoul setup --dry        # 看要装进系统的几样的脚本
```

## 五、怎么定制

### 样子

右键箱子或右键猫：**猫的大小**（小 / 中 / 大；小的那档在终端里也踩得上字）、**猫的描边**（不描 / 细白边 / 粗白边）。箱子能拖，位置记得住。

### 称呼、私人目录

托盘图标右键 → 设置。私人目录的名单就是 `sensors/census/shallow-dirs.txt`，一行一个，也可以直接改这个文件。

### 模型用哪个

托盘 → 设置，或者：

```powershell
ysoul channel                          # 列出这台机器上发现的通道
ysoul channel use 编号1 编号2           # 强模型按这个次序用，前一条不通就换后一条
ysoul channel cheap 编号                # 跑腿的小活用哪条
ysoul channel auto                     # 恢复默认
```

它从四个地方发现通道：

| 来源 | 怎么让它发现 |
|---|---|
| **Claude Code** | 装好并登录，命令行里能运行 `claude` |
| **cc-switch** | 在 [cc-switch](https://github.com/farion1231/cc-switch) 里配一条供应商 |
| **环境变量** | `ANTHROPIC_API_KEY`、`OPENAI_API_KEY`、`OPENROUTER_API_KEY`、`DEEPSEEK_API_KEY`；入口可用 `ANTHROPIC_BASE_URL`、`OPENAI_BASE_URL` 改，模型名用 `YSOUL_MODEL` 改 |
| **Ollama** | 本机开着就行 |

**推荐用 cc-switch 管通道。** 它是一个给 Claude Code、Codex 这些工具切换供应商的小程序：各家的入口、密钥、模型名在它里面配一次，ysoul 自己读得到，不用再在别处填密钥。用法：装好 → 添加供应商（选应用类型、填入口地址和密钥、填模型名）→ 回到 ysoul 的设置页点"重新找"。

通道只分三种说话的格式：Claude Code、Anthropic 的 Messages、OpenAI 的 chat/completions。后两种没有现成的工具循环，由 ysoul 自己跑，每次读写文件前在进程内过同一道门。给 Claude Code 配的中转如果只认 Claude Code 客户端，本机有 `claude` 命令时会自动经由它去问。

密钥只在内存里，不落盘。存下来的只有"用哪一条"的编号。

### 它怎么说话、怎么做事

| 想改 | 改哪 |
|---|---|
| 说话的规矩、什么事该怎么办 | `prompts/system.md`。不用重新编译。`{{owner}}` 和 `{{root}}` 会被填上 |
| 它的脾气 | `seed/temperament.md`（出生前）；出生后它自己写在 `memory/me/core.md` |
| 它记得的任何事 | `memory/` 下的笔记，直接改 |
| 闲话多久一次、几分钟算走开、内存多少算不舒服 | `app/ui/app.js` 的 `behave` 和 `onOccasion`、`runtime/src/pulse.rs` 开头的几个数 |
| 哪些命令算只读、可以直接跑 | `runtime/src/shell.rs` 开头的三张表 |
| 界面操作能按哪些键 | `runtime/src/uia.ps1` 里的键表 |
| 猫的画法和动作 | `design/ysoul-surface-lab.html`（能点的样稿）。改完运行 `node app/tools/extract-cat.mjs` 重新生成引擎 |
| 皮肤 | `design/ysoul-skin-lab.html`。现在只有黑猫一件，其余四件的设计在里面，还没做，欢迎接手 |

界面文件是编进程序里的：改了 `app/ui/*` 或 `runtime/` 要重新 `cargo build --release` 并重启。

### 接进系统的东西

`ysoul setup` 能装的：`menu`（右键菜单）、`ys`（终端短命令）、`start`（开始菜单里的"问 ysoul"）、`claude` / `cursor` / `codex`（这几个工具干完一轮活告诉它一声，只说在哪个目录）。每样都是一张票，都能在票上撤回。

## 六、它能动什么、不能动什么

| | 怎么走 |
|---|---|
| 读文件、搜目录、查进程和服务、读注册表、`git status / log` | 直接做。读写前由程序对地图 |
| 打开文件、网页、程序；问一个命令行程序怎么用 | 直接做 |
| 在别的程序里滚动、翻页、放焦点 | 直接做 |
| 在别的程序里点、填、打字、按回车、右键、拖 | 放开过的程序直接做；没放开过的递票 |
| 改注册表、改设置、删东西、停服务、在记忆之外写文件、任何它看不懂的命令、把活交给别的 AI 工具 | 递票 |
| 密码框、安全软件的窗口、系统的提权确认、聊天和邮件类的程序 | 不碰 |
| 私人目录 | 不看。你亲手交来的那一件除外 |

把关的是程序，不是提示词里的一句"不要碰"。换个写法绕不过去：`..`、大小写、网络路径、从上层整个搜、拼出来的路径，都试过并堵上了。

它**没有**的能力：操作不在前台的窗口；操作既不交出界面、又没留任何口子的程序（部分游戏和老式编辑器，那时只能看图）；不经你点头就以管理员身份做事。

## 七、隐私

- **不留**：密钥的内容、你的姓名邮箱账号、聊天和邮件的内容，不进它的记忆。
- **不出这台机器**：`local/` 整个目录不进仓库——票、动作记录、发给模型的留底、截图、原始的日记。
- **出这台机器的只有两条路**：发给模型的那一份（先遮密，留底在 `local/outbound/`，你随时能查）；推到你自己的仓库的那一份（记忆和代码）。
- **截图**一次一张，用完就删。**不听**，没有麦克风相关的任何东西。
- **日记**：原始的一行一行（窗口标题）只在本机；每天那几句总结在 `memory/days/`。
- 它自己的三条底线：不欺骗、不隐藏、不抗拒关停。托盘里的"退出"随时可用。

第一次上手时帮你把私人目录找全的脚本、推仓库之前的审查脚本，见 `tools/`。

## 八、目录、文档、约定

| 目录 | 内容 |
|---|---|
| `app/` | 桌面上那只（Tauri）。`ui/` 界面，`src-tauri/` 后端，`tools/` 从样稿取引擎的脚本 |
| `runtime/` | 核心库和命令行（Rust） |
| `memory/` | 它的记忆。`us/places.md` 是家的地图，`days/` 是每天的总结 |
| `prompts/` | 提示词 |
| `seed/` | 你交给它的那段话：脾气的种子 |
| `sensors/` | 普查：把这台机器列成纯文本清单 |
| `design/` | 能点的样稿：皮肤、操作面 |
| `docs/` | 设计文档 |
| `tools/` | 审查和导出的脚本 |
| `local/` | 只留本机，不进仓库 |

| 文档 | 内容 |
|---|---|
| `docs/00` | 机主的原话和历次决定。一切设计的出发点 |
| `docs/01–07` | 愿景、安全边界、推导、张力、表现形式、记忆、出生与架构 |
| `docs/08` | 每一步做了什么、验证了什么、没验证什么 |
| `docs/10` | 调研：别人怎么做"掌握一台机器"和"过日子" |
| `docs/11` | 欠账清单 |
| `docs/12` | 掌握本机：地图、门、MCP、票、命令行、界面操作、模型通道 |
| `docs/13` | 过日子：脉搏、日记、念头、闲话、反思、回忆 |
| `docs/14` | 操作面：屏幕上有什么，各自什么时候出现 |
| `docs/15` | 立新学科的流程；敏感内容怎么办 |

约定：文件名和字段用英文，内容用中文。提交说明 `<type>: <说明>`，记忆的提交用 `mem:` 开头。功能变了，这份文档和 `docs/11` 跟着改。
