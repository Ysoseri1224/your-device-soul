# Device Soul（ysoul）— 掌握本机

> 2026-10-12。这一份取代 `09-hands.md`（四档手脚，已被否）和 `10` 第三节甲的骨架。
> 写的是已经做出来、在真机上跑通的东西，不是打算。每一节末尾标了对应的程序。
> 出发点是机主的两句话："它应该知道文件 x 在抽屉 X 里，也同时知道它能对 X 干什么，能对 x 干什么"；"我想让他帮我改个注册表，他就去做了"。

---

## 一、总的样子

它在这台机器上能做的事分成三类，三类走三条不同的路：

| 类 | 例子 | 怎么走 | 谁把关 |
|---|---|---|---|
| 看 | 读一个文件、搜一个目录、查此刻前台是什么、截前台窗口一张 | 直接做 | 家的地图 + 私人名单，由程序在每次调用前核对 |
| 摆给他看 | 打开一个文件、在资源管理器里定位、打开一个网址 | 直接做 | 同上（只能摆它能看的） |
| 改变机器 | 改注册表、改设置、删东西、停服务、在记忆之外建文件 | 递一张票，他点了"做"才执行 | 机主本人 |

只有一处例外：它自己的记忆（`memory/`）读写随意。那是它的笔记本。

这样分的依据是 `10` 第二节的两条结论：把关必须由程序做，不能靠提示词里一句"不要碰"；模型自己选的都算没授权，只有机主说过的才算。

## 二、家的地图

地图是记忆里的一份笔记 `memory/us/places.md`，里面一张表，一行一个地方：

| 地方 | 是什么 | 看 | 放 | 改 | 扔 | 运行 | 依据 |
|---|---|---|---|---|---|---|---|

- 五件事分开算：看（读内容）、放（添新东西）、改（动已有的）、扔（删）、运行。
- 写得更具体的一行盖过笼统的一行。`D:\a\b` 有一行时，`D:\a\b\x` 归它管，不归 `D:\a`。
- 没写的地方：能看，不能动。
- 依据一栏写机主哪天说的原话，或者"我猜的"。猜的只给"看"。
- 每次思考都带着这张表，所以它知道自己在哪能做什么，不用试了才知道。

### 地图怎么长出来（认家）

机主说的是"应该让模型问我哪些目录可操作哪些是只读的"。流程：

1. 它想动一个地图上没写的地方，或者机主提到某个目录时，它问："这里我能做什么？"
2. 机主回答。
3. 它用 `place` 工具递一张**改地图的票**：哪个地方、能做哪几样、依据是机主的哪句话。
4. 机主在桌面上点"做"，程序把那一行写进地图。点之前地图不变。
5. 这张票和别的票一样可以撤回，撤回就是把那一行拿掉（原来有旧的一行就换回去）。

地图它自己改不了：门会拦下它对 `places.md` 的直接改写。原因是地图就是权限，它自己能改就等于自己给自己授权。机主可以直接用编辑器改这份文件。

### 机主亲手交来的那一件

私人名单管的是"它不主动去翻"。机主的原话："不让看是不让主动看，以我的要求为准。"

所以这三种情况，程序直接把那一件放开给它看，不用票：

- 在资源管理器里右键"交给 ysoul"；
- 把文件拖到箱子上；
- 机主在自己说的话里写了一个路径（`「」` 里的，或者盘符开头的），而且那个路径确实存在。

放开的规矩：只放开那一件（是文件夹就是那个文件夹里面的）；只能看，不能改；半小时后失效。旁边的文件照旧看不了。

只认机主亲口说的话。程序附上的内容（他选中的字、票的结果）、它从文件里读到的路径，都不算。依据还是那一条：模型自己选的都算没授权，机主说过的才算。

### 私人的地方

机主列为私人的目录不在地图上，另有一份名单（`sensors/census/shallow-dirs.txt`，和普查共用）。名单里的地方它连看都不能看，由程序强制。名单不进它的上下文，所以这些目录的名字不会每次思考都被带出去。它碰到了会被拦下，被告知"这里不能看"，仅此而已。

名单里的目录如果机主想放开其中一个子目录，在地图上给那个子目录添一行就行，具体的盖过笼统的。

> 程序：`runtime/src/places.rs`（读表、判断、添行撤行、统一路径写法），12 个测试。

## 三、那道门

强模型经由 Claude Code 工作。Claude Code 在每次调用文件工具（Read、Glob、Grep、Edit、Write）之前，会先把"用哪个工具、对哪个路径"交给一个钩子程序。这个钩子就是 `ysoul gate`：

- 读：对地图查"看"。
- 写一个不存在的文件：查"放"。写一个已有的、或者改：查"改"。
- 搜索没写路径：按它当时所在的目录算。
- 相对路径按它所在的目录补全后再查。
- 目标是地图本身：读可以，改不行。
- 不认识的工具：不放行。
- 钩子送来的东西读不懂：不放行。

不放行时，钩子以失败退出，并把原因写给模型，例如"地图上写着 X 不能改（机主 2026-10-11 说的）。要做，先问机主"。模型看得到这句话，所以它知道为什么被拦、该怎么办。

判断只看"对哪个路径做什么"，不看模型怎么解释自己的意图。

### 换个写法绕不过去

写完之后我自己当了一回对手，找到五条能绕过去的路，都堵上了，各有测试：

| 绕法 | 例子 | 现在 |
|---|---|---|
| 用 `..` 走出去 | `memory\..\..\personal\x` | 先把 `.` 和 `..` 算掉再比 |
| 同一个地方的别的写法 | 大小写、结尾加点或空格、`\\?\` 前缀、`文件:流名`、短文件名、目录联接 | 统一成一种写法；路径上存在的部分问系统要真名 |
| 网络路径和设备路径 | `\\localhost\D$\...`、`\\.\PhysicalDrive0`、只写盘符的 `D:x` | 不是本机盘上的完整路径一律不放行 |
| 从上层整个搜 | 在 `D:\` 里搜全文，把下面私人目录的内容一并搜出来 | 要搜的目录下面有不能看的地方，就不让整个搜，要它缩小范围 |
| 匹配式自带路径 | Glob 的匹配式写成 `D:/私人目录/**` | 取通配符之前那一截目录来判断；通配符后面还有 `..` 的直接拒 |

另外两处：

- 地图和私人名单这两份文件决定它的权限，哪怕地图把整个项目都放开，它也改不了这两份；私人名单它连看都不能看。
- `open` 原先经过命令解释器，网址里一个 `&` 就能夹带别的命令。现在不经过它，并且只认 http 和 https 的网址。

没堵的、知道的：两个程序之间的时间差（门判断完到工具真正去读之间，路径被换成链接）。要利用它得先能在机器上建链接，而它没有这个手段。

命令行后来也给了，门是怎么看命令的，见第五之二节。

> 程序：`runtime/src/gate.rs`，11 个测试；挂接在 `runtime/src/strong.rs`。真机验证：让它在 `D:\SOUL\local` 建文件，被拦下，它转而递了票。

## 四、感官和手：指向本机的 MCP

`ysoul mcp` 是一个只走标准输入输出的服务，不开网络端口。强模型思考时挂着它；机主自己平时用的 Claude Code 也挂上了（用户级配置，名字 `ysoul`）。

| 工具 | 做什么 | 把关 |
|---|---|---|
| `now` | 前台是哪个程序、在哪个地方、窗口标题、多久没动；内存和各盘剩余；所在仓库的分支、未提交改动数、最近一次提交说明 | 聊天和邮件类程序不报标题；仓库在不能看的地方就不报 |
| `where` | 一个路径在地图上算哪里，五件事各自行不行 | — |
| `open` | 用默认程序打开文件、文件夹、网址 | 对"看" |
| `reveal` | 在资源管理器里定位到文件 | 对"看" |
| `look` | 把前台那个窗口截成一张图，返回路径，它再去读 | 聊天和邮件类程序不截；一次一张，不连续 |
| `mark` | 在屏幕上圈出一处，或在一处旁边留一句批注 | 要先 `look`；四十个字以内；四十五秒后消失 |
| `tag` | 在机主此刻用的窗口上沿夹一张小条 | 四十个字以内；半小时后消失；同时最多六个记号 |
| `ticket` | 递一张票 | 机主点头 |
| `place` | 递一张改地图的票 | 机主点头 |
| `tickets` | 查之前的票后来怎么样 | — |

`look` 用的是机主给的那个授权："看不懂时截一张，可以给"。平时它靠 `now`（进程、窗口标题、仓库状态）就能知道机主在干什么，这也是机主的意思："活动进程和日志……本身可以代替截屏"。

> 程序：`runtime/src/mcp.rs`（6 个测试）、`runtime/src/sense.rs`、`runtime/src/hands.rs`。

## 五、票

一张票写四样：**做什么**（一句机主读得懂的话）、**在哪**、**怎么撤回**、**要运行的脚本**（PowerShell 7）。需要管理员权限的票单独标出。

一张票的一生：

```
递出（waiting）──机主点"做"──▶ 执行 ──▶ 做完（done）──机主点"撤回"──▶ 已撤回（undone）
      │                          └──▶ 没做成（failed，留着输出）
      └──机主点"不做"──▶ 作废（refused）
```

- 递票不等于执行。它递完只说一句"票递过去了"。
- 票出现在桌面上箱子的上方，猫举牌。箱子上的数字是等着的票数。
- 执行时猫是"干活"的样子；成了是"高兴"，没成是"出错"。
- 做完的票留在原处，上面有输出和"撤回"按钮，机主点"知道了"才收走。
- 每一次做、不做、撤回，都往 `local/actions.jsonl` 记一行。这是动作记录。
- 下一轮对话时，"最近的票"会带在它的上下文里，所以它知道上一张票后来成没成。
- 需要管理员权限的票：执行时系统弹一次提权确认，等于机主亲手运行。常驻的程序本身不持有管理员权限（`02` 的规定不变）。
- 一张票失败了，或者被火绒拦了，它就停下照实说，不换办法重试。

撤回脚本由它在递票时一并写好，要求是"动之前先把原样备份或导出，撤回时用备份恢复"。真的撤不回的事，票上会写"撤不回"，由机主决定做不做。

### 什么事走票，什么事不用

- 机主明说要它做的某一件事，落在它不能动的地方：递票做这一件。点头就是同意这一次，不用改地图。
- 机主说了某个地方以后它可以自己动：改地图的票。之后那里的文件它直接改，不再递票。
- 注册表、服务、系统设置、装卸软件：永远走票。这些没有"地方"可以放开。

> 程序：`runtime/src/hands.rs`，8 个测试。真机验证：递票 → 做 → 文件出现 → 撤回 → 文件消失，动作记录两行。

## 五之二、命令行：门会看命令

它现在有一个 `run` 工具，能跑 PowerShell 命令。给它命令行最大的问题在 `12` 第三节写过：命令可以绕过文件工具，地图就形同虚设。

我的做法是**不去判断一条命令"安不安全"，只判断程序"看不看得懂"**。看得懂的只读命令直接跑；别的一律转成票，由你过目。

为什么不分析安全性：路径可以拼出来（`'D:\per' + 'sonal'`），可以从一个文件里读出来，可以顺着管道传给下一条命令。这些静态分析追不完，追漏一条就是一个洞。所以不追。

"看得懂"的定义，由 PowerShell 自己的语法分析器来判（`runtime/src/judge.ps1`，只拆不跑）：

- 只有一条管道，没有分号、赋值、判断、循环。
- 第一段是一条**已知只读**的命令（列目录、读文件、搜字样、看进程和服务、读注册表、`git status / log / diff --stat` 这类），参数全是写死的值。
- 后面几段只做筛选和排版（`Where-Object`、`Select-Object`、`Sort-Object` 等），里面不许再套命令。
- 哪里都没有变量（`$_` 除外）、方法调用、类型转换、字符串拼接、子表达式、重定向。

过了这一关，再把第一段碰到的每个路径拿去对地图，规则和文件工具完全一样（包括"从上层整个搜"那一条）。都过了才跑，而且是在 PowerShell 的受限语言模式下跑，最多一分钟，输出先遮密再交给模型。

三种下场：

| 命令 | 下场 |
|---|---|
| 只读、看得懂、碰的地方都能看 | 直接跑，输出给它 |
| 会改东西的，或者程序看不懂的 | 自动转成一张票，你点头才跑 |
| 明确要碰不能看的地方 | 不跑，也不递票 |

另外几条：

- **git 历史只给看提交说明**。`git log` 可以，`-p`、`git show`、拿旧版本来 `diff` 都不放行。这是之前答应的：旧提交里有你的个人信息。
- **进程的窗口标题不给**。`Get-Process` 的默认表格不带标题；会把标题打出来的写法（选 `MainWindowTitle`、`Format-List`、选全部属性）转成票。标题里有你在和谁聊天。
- **环境变量、证书这些"盘"不给读**，里面可能有密钥。注册表的 HKLM 和 HKCU 可以读。
- 每一条命令和它的下场都记在 `local/runs.jsonl`。

代价：稍复杂一点的只读命令（比如要做个除法换算单位）也会变成票。宁可多问你一次。

> 程序：`runtime/src/shell.rs`、`judge.ps1`。测试里有 10 条该直接跑的、29 条该转票的、11 条该拒绝的，全部照此判断。真机：问它"哪三个进程最占内存，现查"，它自己写了一条管道，直接跑出了结果。

## 五之三、界面操作：替你点别的程序

走的是 Windows 自带的"界面自动化"（给读屏软件用的那一套），不是认图点坐标。它拿到的是"这是一个叫保存的按钮"，点的是那个按钮本身，所以窗口挪了位置、换了缩放都不会点错。

| 工具 | 做什么 |
|---|---|
| `ui_read` | 读你此刻那个窗口里的文字。比截图准，也省 |
| `ui_see` | 列出窗口里能动手的东西（按钮、输入框、菜单项、页签、链接），每样一个编号 |
| `ui_do` | 按编号点一下、填一格、把输入位置放过去 |
| `mark` 加 `anchor` | 批注跟着一段字走（见 `14`） |
| `launch` | 按名字打开一个程序 |

**走动不用票**：滚动、把输入位置放过去、翻页键（方向键、Home、End、PageUp、PageDown、Ctrl+Home、Ctrl+End），在哪个程序里都直接做，也不留爪印。它们不改任何东西，和"看"是一类。要票的是真动手的：点、填、打字、回车、右键、拖。

**它会适应你的授权**：你在同一个程序里点过两次"做"，程序就把这个程序记到地图上（依据写"你连着点了两次头"），之后它在里面直接动，不再递票。票的结果里会告诉你这件事，要收回在地图里点掉那一格。机主的原话："它太墨守成规了，应该逐渐适应我的操作习惯和授权才对。"

**少让你点头**是写进它规矩里的：能不用票的办法优先（开网页用网址、滚动用滚动、读内容用读）；一件事里要动手的几步并成一张票；票没做成是它自己写错了（键名、编号），就直接改对重来，不停下来问你。

**谁把关**（做法取自 Codex 的"按程序放行"）：

- 你在地图上放开过的程序，它直接动，每一下都留一张做完的票，桌面上有爪印可查。
- 没放开过的，这一下变成一张票。票上有三个按钮：**做**（只这一次）、**这个程序以后都行**（做这一次，并在地图上记一行 `程序:名字`）、**不做**。
- 地图上"程序:名字"那一行和别的行一样，你可以在地图窗口里点一格收回。
- 永远不碰：密码框、安全软件（火绒）的窗口、系统的提权确认、聊天和邮件类的程序、它自己。
- 动手之前程序会核对：前台还是不是那个程序，那一项还是不是那个名字。界面变了就不动，让它重新看。

**动作一共七种**：点、直接填字、一个键一个键地打（填不进去时用）、按一个键、点右键叫出菜单（弹出的菜单会并进下一次 `ui_see` 的清单）、拖到另一项上、把输入位置放过去。

**连着做**：`ui_do` 可以带上"接着做的几步"（最多八步），每一步按名字找那一项，动手前重新看一遍窗口；哪一步找不到就停在那一步，并说清已经做了哪些。没放开过的程序，整串是一张票。

**你选中的字**：你在别的窗口里选中一段字再跟它说话，程序把那段字一并带给它，"这个""这句"指的就是它。

**打开程序不走票**，因为没有什么可撤回的。而且不经过模型：你在说话的地方或者就地问一句里打"打开 DeepL"，或者只打"DeepL"，程序自己对上名字就直接开了，零点几秒。规则是：你明说了"打开"，名字对得上就开；只打了一个词，要一字不差或者以它开头才开，免得把一句普通的话当成要开程序。程序清单来自系统的开始菜单（这台机器上 362 个），一天更新一次。

**一件事有好几步、中间要等票的**：它递完票就停。你点了之后，桌面上那只把结果告诉它（一句以"〔程序：……〕"开头的话），它接着做剩下的；一件事最多这样接六次。先前它递完票就没了下文，要你"点完跟我说一声"。

**从它看到、到你点头，界面可能动过**：编号对不上时，程序重新看一遍窗口，按名字和种类再找那一项；找到了照做，找不到才算没做成。

**在浏览器里**：搜东西、开网页不去点地址栏，直接打开网址（不用票）。页面上的东西按从上到下的次序编号，可以只看某一种（比如只看链接），所以"倒数第二个链接"数得出来。清单的上限从 90 样加到了 400 样。

**做不到的**：有些程序不把里面的东西交出来（老式的编辑器、游戏、部分 Electron 程序），那就只能看图。这台机器上的记事本（被替换过的那个）只交出整篇文字，不交出每段的位置，所以在它里面批注跟不了字。

> 程序：`runtime/src/ui.rs`、`uia.ps1`、`apps.rs`。真机：写字板里读出了文字、列出了控件；让它点"最大化"，因为没放开过，转成了票，点头后窗口真的最大化了。

## 五之四、三样装进系统里的东西

都是它自己递票、你点头装上的（2026-10-12 你点了三张），都能在票上撤回：

| 装了什么 | 改了哪 | 用来做什么 |
|---|---|---|
| 资源管理器右键菜单里的"交给 ysoul"（排在菜单最前面） | 注册表 HKCU\Software\Classes 下两处（文件、文件夹） | 右键一个文件，说话的地方打开，路径已填好，这一件它直接能看 |
| 终端里的 `ys` | 你的 PATH 里加了 `D:\SOUL\bin` | `ys 昨晚我弄到哪了` |
| Claude Code 的钩子 | `~/.claude/settings.json` 的 hooks.Stop 多了一条（原文件备份为 `.ysoul-bak`） | Claude Code 每干完一轮活告诉它一声 |
| Cursor 的钩子 | `~/.cursor/hooks.json` 的 hooks.stop（原文件备份为 `.ysoul-bak`） | 同上 |

Codex 只有一个"干完了通知谁"的位置，已经被它自己的 computer-use 组件占着。做法是不顶掉它，而是把那一行改成先经过 ysoul 的"转达"（`ysoul relay`）：转达先照原样运行原来那个程序，参数一个不动，再给自己记一笔。票已递（2026-10-12），等你点。Codex 更新时可能把这一行写回去，那样只是 ysoul 这边又听不到了，不影响 Codex。

**挂这些钩子是为了什么**：它平时只看得到"前台是哪个窗口"。你让 Claude Code 在某个仓库里干了一下午活，在它眼里只是"终端开着"。钩子让这些工具每干完一轮来说一声"我刚在某某目录干完"，它的日记里就多一行，反思和回答"我今天干了啥"时用得上。这是你当初说的"hooks 当然可以且不限于此"。

挂好的：Claude Code、Cursor（都是你点头装的）。Codex 的票已递。别的工具没有装钩子的地方，或者这台机器上没在用。

钩子只说"在哪个目录"，不说干了什么；同一个目录十分钟内只记一次；不能看的地方不记；ysoul 自己思考用的目录不记。记成日记里的一行。

## 五之五、模型通道：它自己去发现，用哪条你定

机主的话："我总有不用 Claude code 的时候（我也心疼钱）。"所以强模型不再写死走 Claude Code。

**发现**。启动设置页或者跑 `ysoul channel` 时，它去四个地方找：`claude` 命令在不在；cc-switch 的库里配过哪些供应商；环境变量里有没有密钥；本机的 Ollama 开没开。这台机器上找到了 17 条。

**三种说话的格式**。别的都是这三种的变体：

| 格式 | 谁用 | 工具和把关 |
|---|---|---|
| Claude Code | 本机的 `claude` 命令 | 它自带文件工具；每次调用前经钩子问 `ysoul gate` |
| Anthropic 的 Messages | 给 Claude Code 配的中转、DeepSeek 的 anthropic 入口 | ysoul 自己跑工具循环（`agent.rs`） |
| OpenAI 的 chat/completions | OpenRouter、Ollama、各家兼容入口、给 Codex 配的 | 同上 |

后两种没有现成的工具，所以 ysoul 补了五样文件工具（读、列、搜、写、改），加上它本来那些（now、run、ticket……）。每次调用在进程内过**同一个** `gate::decide`，和钩子那边一字不差。一圈一圈地问，最多二十四圈。

**一个实际遇到的情况**：有的中转只认 Claude Code 这个客户端，直接按 Messages 格式去问会被拒。所以本机有 `claude` 命令时，cc-switch 里给 Claude Code 配的那些，是让 `claude` 带着那条供应商的入口和密钥去问（工具和把关照旧走钩子），不成再退回自己直接问。

**选择**。强模型是一个次序：按次序试，前一条不通（余额不足、被拒、超时）就换下一条。跑腿的另选一条便宜的。没选过时：有 Claude Code 先用它。存下来的只有编号（`local/channels.json`）；密钥每次现取，只在内存里。

**会话**。Claude Code 的会话归它管。另两种的对话历史存在 `local/sessions/`，太长了从一句机主的话开始截掉前面的。换了格式就另起一场。

**现在的限制**：看图（`look` 截的那张）只有经由 Claude Code 才读得了，另两种格式下它会说读不了。

> 程序：`runtime/src/channels.rs`（4 个测试）、`agent.rs`（4 个测试）、`strong.rs`。
> 真机：三支都跑通了。OpenAI 格式经 OpenRouter 的 gpt-4o-mini 问"D 盘还剩多少"，它自己调了 `now`，六秒答出。Anthropic 格式经 DeepSeek（机主充值之后）一句话问两件事，它自己跑了一条命令、读了一份笔记，十二秒答出。只认 Claude Code 客户端的中转由 `claude` 带着去问，十一秒答出。

## 五之六、它现在能不能"自由调度这台机器上的任何程序"

不能说"任何"。分开说：

| 它能 | 怎么做到的 |
|---|---|
| 打开开始菜单里的任何程序 | 按名字找，直接开 |
| 用任何程序打开一个文件或网址 | 交给系统默认的程序 |
| 跑任何命令行程序 | 只读又简单的直接跑；别的变成票 |
| 操作**前台**那个程序的界面 | 经"界面自动化"：点、填、打字、按键、右键、拖。放开过的程序直接动 |
| 知道几个 AI 工具刚干完一轮 | 钩子。只是"听见"，不是"指挥" |

| 它不能 | 为什么 |
|---|---|
| 操作不在前台的窗口 | 现在只对前台那一个动手 |
| 操作不把界面交出来的程序 | 部分游戏、老式编辑器、自己画界面的程序，界面自动化看不见里面 |
| 碰聊天、邮件、安全软件、密码框 | 规矩 |

### 程序自己的接口：脚本找"有什么"，它自己学"怎么用"

上一版这里写的是"没有给任何程序写专门的对接"。机主问为什么不能发现。能，而且不该一个程序一个程序地写对接。分两层：

**第一层，脚本**。普查多了一个采集器（`sensors/census/collectors/97-handles.ps1`），只读注册表和 PATH，把每个程序留给外面的口子列成 `body/handles.tsv`。这是确定的事，不该花模型去猜：

| 口子 | 是什么 | 这台机器上 |
|---|---|---|
| scheme | 程序向系统登记的网址前缀（`vscode://`、`ms-settings:`）。打开这种网址就是叫那个程序做一件事 | 179 个 |
| com | 程序登记的自动化接口（`Word.Application`）。脚本里一句 `New-Object -ComObject` 就能指挥它 | 10 个 |
| cli | 能在命令行里直接叫的程序 | 20 个 |
| agent | 能不开界面、直接交给它一件活的 AI 工具 | 2 个 |

**第二层，它自己**。清单只说"有这个口子"，不说怎么用。它要用哪个，就现问：清单上的命令行程序问用法、问版本（`ffmpeg --help`、`git log --help`）是直接跑的，不用票；弄明白了记在 `body/tools-seen.md`，下回不用再问。真去调用还是走老路：只读的直接跑，会改东西的是票。

所以公开版里也是这两层：新用户出生时脚本把清单列出来；用法由它在用的时候自己学、自己记。不预置任何"某某程序怎么用"的知识，那种东西写了就过时。

### 指挥别的 AI 工具

`delegate` 工具：把一件活交给 Claude Code、Codex 这类（清单里的 agent），让它在某个目录里不开界面地做完。

- 那个工具会自己读写那个目录里的文件，不经过 ysoul 的门。所以这**永远是一张票**：你看得到交给谁、在哪、交的原话是什么，点了才开始。
- 它做完，票上是它的回话。撤不回；它改了什么，看那个目录的 git。
- 交出去的话原样传过去。那个工具看不到 ysoul 和你之前聊过什么，所以它要把话写全。
- 适合的活：要在一个仓库里改好几个文件的编程活。那是它们的本行，ysoul 自己不该一个文件一个文件地去改。

配上钩子就是来回的：它交出去一件活，那个工具干完，钩子告诉它"干完了"。

钩子挂好了的：Claude Code、Cursor。Codex 的票递过，等你点。

## 五之七、第一次启动的设置页

写死的东西有三样：根目录、怎么称呼机主、私人目录的名单。现在：

- **根目录**：程序从自己所在的位置往上找"同时有 `memory` 和 `seed` 的那一层"。
- **称呼**：存在 `local/config.json`。提示词里写的是 `{{owner}}`，拼的时候填上；`{{root}}` 同理。
- **私人目录**：还是那一份名单，设置页改的就是它。

第一次启动（还没做过设置）时，桌面上那只会先打开一个设置页（`app/ui/setup.html`）：称呼；私人目录（列出各个盘的顶层目录供点选）；模型通道（列出发现的，点圆圈定次序，点"跑腿"定小活用哪条）。以后从托盘菜单的"设置"再打开。

## 六、器物的用法

"知道厨房在哪"之后还要"知道锅怎么用"。这一层目前靠两样：

- 普查留下的清单（`memory/body/` 下三十来份），它查得到装了什么、在哪、什么版本、谁在开机时启动。
- 它自己的笔记 `memory/learned/`：用过一样东西、踩过一个坑，记一条。

没有做成程序的部分：给每样常用工具写一份"怎么用"的卡片并在用到时自动带上。先看它实际递出的票里哪些工具反复出现，再决定值不值得做。

## 七、还没做的

- 界面操作里的组合键只认一张固定的表（回车、Tab、Esc、方向键、Ctrl+S/A/C/V/X/Z/Y/F 等）。关窗口、切程序、系统键有意不在表里。
- 文件变化的感知（哪些文件刚被改过）。机主的意见是"只注意活跃的仓库和 git 不行吗"，现在就是这么做的。
- 各 AI 工具的钩子（知道机主刚让 Claude Code 干了什么）。
- 资源管理器右键里的"交给 ysoul"、终端里的 `ys` 短命令。
