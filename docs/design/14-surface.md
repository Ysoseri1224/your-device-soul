# Device Soul（ysoul）— 操作面

> 2026-10-12。这一份取代 `10` 第三节丙的骨架，并把 `05` 里"猫的窗口"的说法更新到现在的样子。
> 机主的话："和一个悬浮在屏幕上层的 chatbot 似乎没什么区别……操作和反馈都不是单独一个聊天框和信息栏可以承载的。"
> 样稿在 `design/ysoul-surface-lab.html`（十个场景，能点）。这一份写的是：样稿里的哪些已经在真桌面上跑着，各自什么时候出现。

## 一、它在屏幕上是什么

一层盖住整块屏幕的透明窗口，永远在最上面。这一层上除了画着东西的地方，鼠标点击全部穿过去落到下面的程序上。画着的东西有：

- **箱子**：它的窝。默认在右下角任务栏上，可以拖到任何地方，位置记得住。
- **猫**：出了箱子就是自由的，和箱子没有连线。
- **几样小东西**：此刻条、气泡、票、箱子摊开的一块、说话的地方。

这一层不抢键盘：启动时不拿焦点，只有机主打开"说话的地方"时才拿。它自己不算"前台程序"：机主正跟它说话时问它"我在干嘛"，它报的是机主之前用的那个窗口。

> 程序：`app/src-tauri/src/main.rs`（盖屏、点击穿透、脉搏）、`app/ui/app.js`（什么时候做什么）、`app/ui/catrig.js` 和 `cat.css`（猫的画法、动作、寻路，由 `app/tools/extract-cat.mjs` 从样稿生成，不手改）。

## 二、猫把真的窗口当猫爬架

任务栏的上沿是零线。每个窗口的上沿，没被别的窗口挡住的那一截，是一层台面。台面由程序每 0.7 秒量一次（最小化的、隐藏的、系统自己的窗口不算）。

- 一次跳的极限：水平和竖直都是屏幕的三分之一。
- 一次够不着，就找中转的台面，多跳几次。
- 没有路，就走到台面尽头，跳出屏幕侧边，片刻之后从目标台面那一侧同样高度的地方跳进来。
- 脚下的台面没了（窗口被关、被挪、被最大化）：落到下面最近的一层。
- 所有的跳和落用同一个重力。

## 三、各个状态什么时候出现

| 想 | 机主跟它说了话，它在想 | 已接 |
| 举牌 | 有票等机主点头 | 已接 |
| 干活（坐着玩毛球） | 票正在执行 | 已接 |
| 高兴（眼里和头边冒星星） | 票做成了；机主点了一下它的闲话 | 已接 |
| 出错（三个叹号） | 票没做成；它想不了 | 已接 |

**它自己逛**：样稿里有个随机乱逛的按钮，程序里没有接。它去哪都有原因：跟着机主、回窝、去睡。没有原因就坐着。这是有意的：一只满屏乱跑的猫会抢注意力，而它该是余光里的东西。

## 四、猫和箱子以外的组件

| 组件 | 做什么 | 现状 |
|---|---|---|
| 此刻条 | 箱子上方一行小字："你在：终端 · SOUL"。让机主随时看得到它以为机主在干什么，错了一眼就知道 | 已做 |
| 闲话气泡 | 它自己起头的一句。九秒淡掉。点一下是"挺好"，右键是"别说了" | 已做（见 `13`） |

| 把文件拖到箱子上 | 打开说话的地方，文件路径已经填好，等机主说要拿它做什么 | 已做，未在真机上拖过 |
| 箱子上的数字 | 有几件事等机主：票、它出生时想好的那段话 | 已做 |
| 右键箱子 | 说话、叫它回箱子、这阵子别出声、退出 | 已做 |
| 夹在窗口上的条 | 一句和某个窗口有关、又不值得打断机主的话。夹在那个窗口的上沿，跟着窗口走；窗口占满屏幕时夹在屏幕顶上；窗口看不见时条也不出现。留半小时，点一下收掉 | 已做。它用 `tag` 工具留 |
| 圈 | 把屏幕上的一处圈出来。圈本身点不着，不挡下面的东西；旁边的说明点一下收掉。留四十五秒 | 已做。它先 `look` 再用 `mark`，说的是截图上的位置，程序换算回屏幕 |

## 五、说话的地方和别的东西怎么分工

机主嫌"聊天框承载了一切"。现在的分工：

- **它有话**：闲话走气泡，要机主决定的事走票，身体状况走猫的样子加一句气泡。都不进聊天框。
- **机主有话**：进说话的地方。
- **机主想知道它怎么看此刻**：此刻条和箱子摊开，不用问。
- **机主想让它做事**：说一句，结果以票的形式回到桌面上，不是一段文字。
- **机主想给它东西**：拖到箱子上。

## 六、"不同意"的全过程

它不赞成机主要它做的事时：

1. 先说理由，一次，说完就停。这是提示词里已有的规矩："你觉得不妥，就说出理由，说一次，然后照做。"
2. 同时猫伸爪把杯子碰倒。杯子在台面上就滚落到任务栏。这是姿态，不是阻拦。
3. 机主坚持：它照做（该递票递票）。不再说第二遍，不拖延，不做一半。
4. 只有两种情况它不做，并且照实说不做：越过 `02` 的底线的事；程序拦下的事（地图、私人名单）。后者它会说"这里我动不了，要动你得先在地图上放开"。

时机是这样接上的：它不赞成时，在回话的第一行单独写 `〔不同意〕`。界面认出这个记号后把它去掉（机主看不到），让猫把杯子碰倒；猫在箱子里就换成"不同意"的样子。五秒后恢复。

## 六之二、上手之后改的（2026-10-12 凌晨）

- **快捷键**：就地问一句优先用 Ctrl+Alt+空格。它被 Claude 桌面版占着时先用 Ctrl+Alt+Y，并且每半分钟再试一次，Claude 一松手就接过来。右键菜单里写着此刻用的是哪个。系统级的快捷键谁先注册归谁，抢不过来；硬抢要装键盘钩子，那会让它看到每一次按键，不做。**所以要你在 Claude 桌面版的设置里把它的快捷键关掉或者换掉**，之后不用重启 ysoul。
- **点别处就收起**：箱子摊开、地图、说话的地方、就地问的那一行、已经到了的回话、做完的票，在它们外面点一下鼠标就收起。等回话的和等你点头的票不收。它只知道"鼠标在它的东西外面按了一下"，不知道点的是什么。
- **猫出来，箱子收到边上**：猫一出箱，箱子滑到最近的屏幕边，只露三分之一。点它、有东西摊开着、猫要回家的时候，它先滑出来。
- **脸朝屏幕中间**：停着的姿势（坐、蜷、站、炸毛、被拎着）在右半边朝左，在左半边朝右。拎着它走过中线，它跟着换一边。
- **不在空中走**：路走到一半脚下的台面没了（你切了窗口，原来的上沿被盖住了），它就地落下，不再沿着已经不存在的台面走。
- **这一层上没有任何转动的东西了**。左右摆是因为页面里有个类名和猫皮肤里一个会摆的类撞了（这是第二次）。除了改名，还加了一条总规矩：皮肤里的动画只作用在猫和箱子身上，别的东西哪怕类名撞了也不跟着动。夹条原来故意歪的那一点也去掉了。
- **笔记直接打开**："你记了我什么"打开的是 `you/said.md` 那份笔记本身，"今天的日记"打开的是今天那一份，不再是打开文件夹。
- **地图上点一格**：那一行留在原处，不再跑到表尾。
- **批注跟着文字走**：`mark` 的 note 给一段原文（`anchor`），批注就钉在那段字上。桌面上那只每秒多一点去问一次那段字现在在哪：滚动了就跟着挪，滚出去了就先不画，切到别的程序也不画，回来再出现。留十分钟。要那个程序肯把文字的位置交出来才行（见 `12` 第五之三节）。

## 六之三、第二次上手之后改的（2026-10-12 下午）

- **票不再被盖住**：有一块摊开着（说话的地方、箱子摊开、地图）时，票放到那一块的上面；上面放不下就放到它左边。票的层级也调到了最上。
- **说话的地方不再长出屏幕**：它的底边对齐箱子的底边，内容多了往上长，最高到屏幕高度，里面的对话自己滚动，输入框永远在。
- **两种场合不混**：说话的地方是一场连着的对话，隔了四十五分钟没说就另起一场。就地问的那一行每次都是新的一场，它不会以为还在聊上一件事。
- **就地问的那一行**：能换行（Shift+回车），会随内容长高，长到屏幕边就往上挪。
- **你把它放在哪，它就待在哪**：拎起来丢进箱子，它待在箱子里，直到你叫它出来；放到一个台面上，它待到你换窗口为止。
- **爪印**加了白色描边。
- **在终端里选中的字它看不到**，这个改不了：Claude Code 这类程序自己接管了鼠标，你拖出来的高亮是它自己画的，不是终端的选区，系统那边读不到。按住 Shift 再拖，才是终端自己的选区。

## 六之四、第四次上手之后改的（2026-10-12 下午）

- **叫出那一行输入的办法**，现在有四个：快捷键；点一下托盘里的图标（右键才是菜单）；开始菜单里的"问 ysoul"（按 Win 键打 ysoul 回车，也可以固定到任务栏）；终端里的 `ys`。系统自带的搜索框本身没有给别的程序留接口，能做到的"集成"就是让它搜得到这个快捷方式。
- **打开剪贴板时输入不再消失**：说话的地方和就地问的那一行，在外面点一下不收了（剪贴板面板、输入法选字都算"外面"）。它们改成你真的切到别的程序时才收；说话的地方里要是还有没发出去的字，切走也不收。箱子摊开、地图、做完的票，仍然是点别处就收。
- **爪印**：只画今天最近的五个；更早的缩成一个"+N"，点它或者点箱子，在"今天动过的手"里能看到今天全部的，点开一样能看、能撤回。隔天的不在桌面上，在 `ysoul ticket` 和 `local/actions.jsonl` 里。
- **挡住字了就让开；一行字上面是空的，就踩在那行字上**（第二版）：
  - 第一版是把它身后整块画面算成一个数，稀疏的两三行字（比如终端底下的输入行）会被大片空白冲淡，量出来只有 0.018，远低于门槛，所以它坐在你正打的字上不动。机主发来的截图就是这个情况。
  - 现在的量法：它附近取二十来根"柱子"，每根一个身子宽，从它本来站的那一层往上五百多像素，从上到下切成 6 像素高的一条一条，每条各自算"有多满"（相邻像素亮度差得多的地方占的比例）。一行字所在的那两三条是满的（实测 0.16–0.33），空白是 0。
  - 挡住了：它身子占的那一段里有两条以上是满的。
  - 落脚处：一段够放下身子的空白，这段空白的底下要么是它本来站的那一层，要么是一行字。后一种就是"踩在字上"：那行字临时算一层台面，它跳上去坐着，身子在字上面的空白里。
  - 挑哪个：横着走的路加上往上抬的高度最小的那个。连着两次都挡着才动；动一次之后九秒内不再动。一个落脚处都没有，就回箱子待一分钟。
  - **机主没测到它踩字**，原因有三，都改了：一、他把猫拎起来放到字上去试，而"你亲手放的地方它不挪"把躲字整个关掉了，现在这条只管"不跟着窗口走"，不管躲字；二、旁边有空地时它总是先挪到空地，往上抬的代价算得太重，现在近处有能踩的字就优先踩上去；三、没有"放下来落在字上"这回事，松手后它一路掉到任务栏。现在松手的地方附近（一百来像素内）有一行能踩的字，它落稳之后会站到那行字上。
  - 要它踩得上去，那行字的上方得有一个身子高的空白（约 80 像素，终端里大概四行）。终端里行与行之间没有这么大的空，所以在 Claude Code 里它多半是挪到没字的那一段，而不是踩字；踩字常见于段落之间有空行的文档和网页。
  - 踩在字上的时候：脚下那行字没了（滚走了）它不会悬在半空，会重新找地方；"跟着你用的窗口走"那条规则不会把它叫下来；你亲手放的地方它不挪。
  - 量的时候会把它自己那一层从画面里拿掉几十毫秒，所以量到的是它身后的东西；只算出一串数，像素不留、不存、不出那个函数。

## 七、已知的毛病

- 引擎里猫的大小原本按假桌面的比例定，真桌面上固定为 140 像素宽。没在别的缩放比例的屏幕上看过。
- 猫出箱后站在窗口上沿，会挡住标题栏的一小块；那一块的点击落在猫身上（等于拎它）。
- 样稿里原先不满意的四处改了（2026-10-12）：眼里的星从 8 放到 11，头边的星大了一圈；毛球半径从 8.5 到 11.5；蜷着睡背拱得更高、更接近一个团；转身不再只是两张脸淡入淡出，身子横向收窄到三成再展开，中间那一刻换朝向。前三处在样稿里截图看过；转身是动的，没法从一张图上看。
- 只认主显示器。机主说过不考虑多显示器。

## 八、多显示器：要考虑的点（没做，记在这里）

现在只认主显示器。要支持第二块屏，绕不开这几件事：

1. **一层还是几层**。一层盖住所有屏最省事，但两块屏缩放比例不一样时，一个窗口只能按一种比例画，另一块屏上的猫会忽大忽小、发虚。每块屏一层更干净，代价是猫从一块屏走到另一块屏要在两层之间交接。
2. **坐标**。副屏在主屏左边或上边时坐标是负的；量窗口、圈东西、截前台窗口、躲字，凡是用到屏幕像素的地方都要过一遍。
3. **零线**。任务栏默认只在主屏上。副屏的"地面"是屏幕底边，没有任务栏可坐。
4. **屏幕边缘不再是尽头**。现在够不着的地方它会跳出屏幕侧边再跳进来；两块屏并排时，中间那条边应该是走得过去的。
5. **全屏只管那一块屏**。副屏放着全屏视频，主屏上的猫不该消失。
6. **它跟谁**。你的窗口在副屏上，它是跟过去，还是待在箱子所在的那块屏上只转头看？箱子能不能拖到另一块屏。
7. **插拔**。合上盖子、拔掉线，猫和箱子正好在那块屏上怎么办。

我的想法：分两步。第一步每块屏一层，猫和箱子只活在箱子所在的那块屏上，别的屏上的窗口它只"知道"、不过去；全屏判断改成按屏。这一步改动小，先把"副屏上的事不影响它"做到。第二步才做跨屏走动。
