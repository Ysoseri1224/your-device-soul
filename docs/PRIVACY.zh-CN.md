# 隐私上手

两个脚本、一段话，让头一个小时里不会漏出去你不想给人看的东西。English: [PRIVACY.md](PRIVACY.md)

> 这里用到的几个词——"出生""私人目录""家的地图""票"——在[使用指南第 3 节](GUIDE.zh-CN.md#3-先认识几个词)里有解释。

## 一、出生之前，先把私人目录找全

`birth` 会把这台机器摸一遍。私人名单里的目录只记"有这么个目录"，里面有什么当时不看、以后也不看。

```powershell
pwsh tools/suggest-private.ps1          # 只把候选打出来，什么都不改
pwsh tools/suggest-private.ps1 -Write   # 写进 sensors/census/shallow-dirs.txt
```

它列出名字看着像私人的顶层目录（聊天软件的数据、邮件、文档、照片、下载，名字里带 private / personal / 个人 / 私人 的），再加上你的用户目录。宁可多列。看一遍结果，自己删改这个文件，或者在设置页里改。

## 二、让它来问你

出生之后，把这段话发给它一次：

> 先别做别的，带我过一遍这台机器的地图。一个盘一个盘来，把你只知道名字的顶层目录报给我，一次几个，问我：里面你能不能看，能不能动。我答一个，你递一张改地图的票。我没答过的地方不要打开。我说停就停。

每个回答变成一张票，你点了"做"地图才变。

## 三、推自己的分支之前，先审查

```powershell
pwsh tools/audit.ps1              # 查 git 会推出去的所有东西
pwsh tools/audit.ps1 -Path memory # 或者只查一个目录
```

它找：邮箱地址、账号编号的样子、像密钥的字符串、你的 Windows 用户名、机器名、私人名单里的每一个名字。有命中就打出文件和行号（命中的内容本身遮掉），并以失败退出。

它没法知道的：你的真名、学校、单位。把这些一行一个写进 `local/audit-words.txt`，这个文件不出这台机器。

## 程序本来就在做的

- 发给模型之前遮掉密钥、邮箱、账号编号，并把每一次发出去的原文留底在 `local/outbound/`。
- `local/` 和原始的活动记录不进 git。
- 聊天和邮件类程序的窗口标题从不记录。
